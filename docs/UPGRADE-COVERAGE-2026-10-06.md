# گزارش پوشش ارتقای OMNIX — ۶ اکتوبر ۲۰۲۶

**پاسخ مستقیم: همهٔ درخواست‌ها هنوز کامل نشده‌اند.** کد و آزمون‌های خودکار با آزمون داخل Office واقعی و اتصال به حساب واقعی پرووایدر یکسان نیستند. این گزارش وضعیت قابل‌اثبات را نشان می‌دهد؛ تضمین صفر خطا، دسترسی به تمام Ribbon یا سازگاری با هر مدل نمی‌دهد.

## ارتقای این مرحله

1. مسیر ساخت جدول Excel به دسته‌های پیوسته با نوع و قالب یکسان تبدیل شد. متن با `Value2` و قالب متن، عدد/بولین با نوع واقعی، تاریخ با مقدار OA و قالب تاریخ، و فرمول با `Formula` نوشته می‌شود. متن و فرمول هرگز در یک دسته نیستند.
2. بازخوانی داده‌ها و فرمول‌ها دو خواندن محدود دارد؛ نوع فرمول برای هر دسته بررسی می‌شود. عددی که به متن تبدیل شده، فرمولی که متن شده، یا خواندن ناقص قبول نمی‌شود. شناسه‌های دارای صفر آغازین حفظ می‌شوند. متن خالی مطابق رفتار Excel به سلول خالی قابل تبدیل است.
3. در نمونهٔ ۵۰۰ سلول عددی با ۱۰ ستون، طرح دسته‌بندی ۱۰ نوشتن داده دارد؛ این شمارش ساختاری است، نه ادعای بهبود زمانی اندازه‌گیری‌شده روی دستگاه کاربر. ایجاد جدول، قالب‌بندی، محاسبه و بررسی‌های بعدی همچنان فراخوانی‌های جدا دارند. در دادهٔ کاملاً مختلط تعداد دسته‌ها بیشتر می‌شود.
4. پیش از پذیرش طرح ایجاد چند شیت، تمام آرگومان‌های ساخت و نام‌های مقصد بررسی می‌شوند. مقصد تکراری و شیتی که از قبل وجود دارد، پیش از ساخت اولین شیت طرح را رد می‌کنند. شیت‌های اجراشدهٔ همان طرح در اصلاح/ادامه دوباره به‌عنوان مقصد تازه بررسی نمی‌شوند. این کنترل در مسیر واقعی executor به Excel متصل است؛ عملیات جدید همچنان هنگام اجرا دوباره مقصد را بررسی می‌کند.
5. «حالت آموزشی» به تنظیمات افزوده شد: توضیح کوتاهِ مراحل واقعیِ بررسی، پیش‌نمایش، اجرا و تأیید نتیجه، با حداقل مکث ۸۰۰ میلی‌ثانیه. تنظیمات قبلی آن را خودکار فعال نمی‌کنند. توضیح، فکر خصوصی مدل یا کلیک ساختگی نیست. توقف و محدودهٔ سند همچنان کنترل می‌شوند.

## پوشش همهٔ خواسته‌ها

«پیاده‌شده» یعنی مسیر در کد وجود دارد؛ رفتار واقعی روی دستگاه کاربر جداگانه نیاز به تأیید دارد. «Partial» یعنی فقط بخش محدود خواسته پوشش دارد؛ «Missing» یعنی هنوز تحویل نشده است.

| خواسته | تحویل موجود و محل استفاده | وضعیت |
|---|---|---|
| Custom Provider همیشه اول باشد | Registry و فهرست تنظیمات | پیاده‌شده؛ آزمون رابط |
| اسم کوتاه و متن راهنمای کوتاه | نام‌های Registry و تنظیمات | پیاده‌شده؛ بازبینی بصری واقعی لازم |
| نام، پروتکل، Base URL، کلید، کشف مدل، تست، ذخیره | فرم Custom و Agent Router | پیاده‌شده؛ اتصال واقعی لازم |
| OpenAI و Anthropic compatible | آداپتر Custom و پروب پروتکل | Partial؛ همهٔ endpointها/مدل‌ها تضمین نشده‌اند |
| Agent Router و پرووایدرهای بیشتر | Registry شامل Agent Router، SambaNova، NVIDIA، SiliconFlow و Cloudflare | پیاده‌شده؛ قیمت/سهمیهٔ رایگان روزانه باید از صفحهٔ همان سرویس بررسی شود |
| تنظیمات Local فقط برای Local | نمایش شرطی بخش‌های Local | پیاده‌شده |
| اسکرول فهرست پرووایدر و تنظیمات | کنترل‌های اسکرول فرم | پیاده‌شده |
| کشف مدل و واردکردن دستی | مدل‌های کشف‌شده و Custom Model | پیاده‌شده؛ محدودیت API خود سرویس باقی است |
| Verify سپس انتخاب مدل‌های کارا | ردیف قابل انتخاب، فیلتر Working، جست‌وجو و Keep | پیاده‌شده؛ Working یک پروب ابزار است، نه گواه کیفیت کار کامل |
| نگه‌داشتن چندین مدل | SavedModels جدا برای هر پرووایدر | پیاده‌شده |
| Test Connection مستقل از اجازهٔ ارسال سند | تست مصنوعی و تشخیص پروتکل | پیاده‌شده؛ شبکه/کلید واقعی لازم |
| Save ذخیره کند و به Chat برگردد | مسیر Save تنظیمات | پیاده‌شده؛ آزمون رابط |
| اجازهٔ پیش‌فرض برای Cloud و تغییر معمول | پیش‌فرض CloudAllowed و تأیید اختیاری هر ویرایش | پیاده‌شده؛ تنظیم صریح قدیمی کاربر حفظ می‌شود |
| خوانایی رنگ و حالت روشن/تاریک | Theme و آزمون کنتراست رابط | پیاده‌شده؛ بازبینی روی مقیاس نمایش کاربر لازم |
| پیام طولانی، اسکرول و TXT | ورودی چندخطی و TXT | Partial؛ متن بی‌نهایت پشتیبانی نمی‌شود و محدودیت context سرویس وجود دارد |
| حافظه و پیام‌های قبلی | تاریخچهٔ رمزگذاری‌شدهٔ هر سند، حدود قابل تنظیم و جست‌وجو | Partial؛ همهٔ تاریخچه در هر درخواست فرستاده نمی‌شود |
| انتخاب و کپی تمام گفتگو | Copy all و Transcript | پیاده‌شده |
| مدل بداند در کدام Office و سند است | Runtime envelope، محدودهٔ درخواست و خواندن بومی | پیاده‌شده؛ دسترسی سراسری به همهٔ فایل‌ها نیست |
| تبدیل درخواست ساده به ساخت مفید | Playbookهای میزبان و کسب‌وکار، الگو و طرح اجرایی | Partial؛ شناخت عمومی تمام درخواست‌ها تضمین نشده |
| مشخصات مستقل از مدل اجراکننده | نگهبان عنوان/فرمول/نام شیت در درخواست اصلی | Partial؛ Spec عمومی برای هر سه میزبان هنوز کامل نیست |
| ساخت، بازخوانی، مقایسه و اصلاح | ExecutionPlan و postconditionهای بومی با سقف تلاش | پیاده‌شده برای معیارهای پشتیبانی‌شده |
| اسم دکان در کادر بالای جدول | heading و aboveTable، تطبیق عنوان صریح | پیاده‌شده؛ سناریوی واقعی اضافه شده ولی اینجا اجرا نشده |
| فرمول واقعی، ارجاع درست و نتیجهٔ درست | typed formula و بررسی Formula + Value | پیاده‌شده برای معیارهای طرح؛ همهٔ فرمول‌ها/نسخه‌ها آزموده نشده |
| ردیف کامل، شناسه و ستون درست | table rows/headers/keys، خواندن دسته‌ای | پیاده‌شده؛ دادهٔ تجاری نامعلوم جعل نمی‌شود |
| کار در همان شیت و جلوگیری از شیت تکراری | نگهبان اجرای مجدد و پیش‌بررسی مقصد | پیاده‌شده؛ تغییر مقصد هم‌زمان هنگام اجرا باز بررسی می‌شود |
| اجرای زنده و مرحله‌ای | RevealOperation واقعی، تاریخچهٔ عملیات و مکث قابل تنظیم | پیاده‌شده؛ برای اجرای Object Model کلیک ساختگی نشان نمی‌دهیم |
| حالت آموزشی | توضیح مراحل واقعی در Chat و تنظیمات | اضافه شد |
| رفع هنگ و پاسخ‌دادن Stop | انتظار شبکهٔ async، dispatcher، خواندن محدود، عملیات دسته‌ای و تشخیص فاصلهٔ heartbeat | Partial؛ علت/رفع قطعی هنگ و crash دستگاه هنوز نیازمند trace واقعی است |
| ادامه پس از قطع | checkpoint نسخه‌دار، حفظ هدف و بررسی نتیجهٔ قبلی | Partial؛ ذخیره‌سازی بهترین‌تلاش است و همهٔ قطع‌ها قابل بازیابی نیست |
| شناخت جدول/نمودار/شکل | نقشهٔ اشیای Excel و خواندن صفحه‌بندی‌شدهٔ ساختار Word/PPT | پیاده‌شده برای اشیای پشتیبانی‌شده؛ تصویر کامل همهٔ سند نیست |
| Vision در هر سه برنامه | capture واقعی و ارسال به مدل سازگار | Partial؛ هر مدل Vision ندارد و داوری بصری خودکار کالیبره‌شده کامل نیست |
| دسترسی به همهٔ ابزارها و Ribbon | کاتالوگ محدود ابزارهای پیاده‌شده | Partial؛ دسترسی نامحدود به همهٔ فرمان‌ها نداریم |
| مرجع همهٔ فرمول‌ها و آموزش | مرجع تابع‌های Excel و دستورهای موجود در Learn | Partial؛ پوشش هر نسخه/تمام قابلیت‌های Word/PPT تأیید نشده |
| افغانستان، دری، افغانی و واحد درست | BusinessLocale و راهنما، نمونهٔ AFN و تاریخ مشخص | پیاده‌شده؛ نرخ/مالیات/تبدیل تقویم واقعی خودکار جعل نمی‌شود |
| صدها الگوی باکیفیت و ترکیب خودکار | چهار الگوی Excel شامل طلافروشی چهارشیتی | Missing برای صدها الگو و الگوهای تخصصی هم‌ارز Word/PPT |
| آموزش وزن‌های همهٔ مدل‌ها | راهنما، ابزار و اجرای کنترل‌شده | Missing؛ مدل‌های API را در این پروژه بازآموزی نکرده‌ایم |
| حذف همهٔ نسخه‌های قبلی | حذف Releaseهای قبلی پس از تأیید نسخهٔ جایگزین | محدود به Releaseها؛ تاریخچهٔ Git و فایل‌های رایانهٔ کاربر حذف نمی‌شود |
| تضمین هیچ خطایی باقی نماند | آزمون خودکار و سناریوی واقعی آماده | تأییدنشده؛ چنین تضمینی از CI به‌تنهایی حاصل نمی‌شود |

## آزمون و محدودیت شواهد

آزمون‌های خودکار تازه شامل دادهٔ مختلط، آرایه‌های صفرپایه/یک‌پایه، scalar تک‌سلولی، رد عدد متنی، تشخیص فرمول ازدست‌رفته، رد خواندن ناقص، کاهش دسته‌های نمونهٔ ۵۰۰ سلولی، مقصد تکراری/موجود و چرخهٔ نمایش حالت آموزشی هستند. تمام بررسی‌های موجود نیز باید پیش از انتشار موفق شوند.

اسکریپت functional واقعی Office به سناریوی دادهٔ مختلط، جدول ۵۰۰ سلولی، رد تغییر نوع و پیش‌بررسی مقصد مجهز شد و زمان ساخت را ثبت می‌کند. این اسکریپت روی میزبان دارای Office واقعی اجرا می‌شود. محیط فعلی Linux است؛ نتیجهٔ زمان اجرا، سلامت Office واقعی و اتصال به کلیدهای کاربر در اینجا تأیید نشده‌اند.

## مواردی که هنوز تکمیل پروژه را مسدود می‌کنند

- اجرای نصب دقیق روی Windows/Office، همراه لاگ هنگ و crash همان دستگاه.
- ماتریس آزمون کاربردی endpoint/protocol/model با حساب واقعی و سند آزمایشی هر سه میزبان.
- Spec مستقل و معیارهای محتوا/چیدمان گسترده‌تر برای Word و PowerPoint.
- داوری بصری کالیبره‌شده و مجموعهٔ الگوهای حرفه‌ای آزموده‌شده در هر سه برنامه.
